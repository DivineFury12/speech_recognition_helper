Голосовой ассистент для задач и встреч

Ассистенту можно сказать или написать обычными словами: «Напомни завтра в 10 позвонить Ивану», «Что у меня на неделе?», «А перенеси её на час позже». Он поймёт, переспросит, если чего-то не хватает, сделает и ответит текстом и голосом.

Речь распознаёт GigaAM, команды разбирает GigaChat, ответы озвучивает Silero, записи хранятся в PostgreSQL с pgvector, интерфейс написан на Vue. Всё, кроме GigaChat, работает на своём компьютере или сервере.

В этой версии объединены две ветки: основа из main (слои бэкенда, PostgreSQL, строгая схема команды GigaChat, защита от повторных запросов, уточняющий диалог) и функции из ветки experimental/gigachat-backend (подтверждения, отмена, повторы, озвучка, пользователи, защита, календарь).


Коротко, что умеет

- создаёт задачи, напоминания и встречи голосом или текстом;
- показывает записи за период и ищет старые, в том числе по смыслу;
- понимает «завтра», «в пятницу», «через неделю», «до конца недели» и другие относительные даты;
- переспрашивает, если не хватает даты, времени или названия, и если непонятно, утро имелось в виду или вечер;
- если запись ставится в прошлое («поставь задачу на вчера»), называет конкретную дату и спрашивает, точно ли;
- переносит, сдвигает («на час позже», «на 2 дня»), переименовывает, удаляет записи и отмечает их выполненными;
- перед удалением переспрашивает; ответ «да» понимает и с опечатками («жа», «lf» в английской раскладке);
- отменяет последнее действие: «Отмени последнее»;
- предупреждает о пересечении встреч;
- ведёт повторяющиеся записи: «каждый понедельник», «по будням», с датой окончания; можно изменить или удалить только один раз из серии;
- выполняет несколько команд в одной фразе: «поставь встречу завтра в 10:00 и напомни за час»;
- напоминает заранее: «напомни за 15 минут до встречи», а в браузере показывает уведомление и говорит вслух;
- понимает «я купил молоко» и отмечает задачу «Купить молоко» выполненной;
- не создаёт дубли и не выполняет один запрос дважды при повторе после обрыва связи;
- даёт кнопки быстрых ответов под сообщением и сводку на день;
- отвечает голосом, три голоса на выбор, с регулировкой громкости; озвучку можно перебить голосом;
- отдаёт записи в любой календарь файлом .ics или ссылкой на подписку;
- показывает в шапке, какие сервисы работают;
- лента записей по дням (просрочено, сегодня, завтра, неделя, без срока) с фильтрами и отметкой галочкой;
- карточку можно открыть и поправить руками или создать запись кнопкой «+»;
- приоритет: «поставь важную задачу…», «пометь купить хлеб как важную»;
- светлая и тёмная тема, анимации, мобильная версия с нижними вкладками, установка на телефон как приложение;
- разделяет пользователей по браузерам, защищён кодом доступа, лимитами и заголовками безопасности;
- может работать без голоса, только с текстом;
- работает и без GigaChat: если ключа нет или GigaChat недоступен, команды разбираются правилами.


Как запустить

Нужны Python 3.11 или новее, Node.js, Docker Desktop (только для базы PostgreSQL) и ключ GigaChat.

На Windows одной командой из корня проекта:

    .\run.ps1

Скрипт сам запустит Docker и базу PostgreSQL в контейнере assistant-db (порт 15432), создаст окружение для бэкенда, сделает backend\.env из шаблона, обновит схему базы, откроет бэкенд и фронтенд в двух окнах и браузер на http://127.0.0.1:5173. При первом запуске впишите ключ GigaChat в backend\.env (GIGACHAT_AUTH_KEY) и запустите скрипт ещё раз.

Флаги:

- -NoVoice — без распознавания речи и озвучки, только текст;
- -Prod — собрать фронтенд и открыть всё на одном адресе http://127.0.0.1:8000;
- -NoBrowser — не открывать браузер.

Для голоса и поиска по смыслу в окружении бэкенда нужны torch и GigaAM. Скрипт их не ставит, потому что они весят несколько гигабайт и зависят от видеокарты:

    cd backend
    .venv\Scripts\activate
    pip install torch==2.10.0 torchaudio==2.10.0 --index-url https://download.pytorch.org/whl/cu126
    pip install "gigaam[longform] @ git+https://github.com/salute-developers/GigaAM.git"

Без видеокарты вместо cu126 укажите cpu.

Запуск в Docker целиком (бэкенд, база и интерфейс):

    cd backend
    docker compose up -d --build

Без видеокарты: docker compose -f docker-compose.cpu.yml up -d --build. Интерфейс открывается на http://localhost:8080, API на http://localhost:8000, Swagger на http://localhost:8000/docs. Ключ GigaChat задаётся в backend/.env.


Как получить ключ GigaChat

1. Зайдите на https://developers.sber.ru/studio через Сбер ID.
2. Создайте проект GigaChat API, физлицам доступен бесплатный тариф.
3. В настройках проекта нажмите «Получить ключ» и скопируйте Authorization key.
4. Впишите его в backend\.env: GIGACHAT_AUTH_KEY=ваш_ключ. Модель по умолчанию GigaChat-2.

Ключ хранится только в backend\.env, этот файл в git не попадает. Без ключа маршруты ассистента отвечают 501.


Что умеет ассистент, подробно

Создание. «Напомни мне завтра в 10 утра позвонить Ивану», «В пятницу нужно отправить отчёт», «Добавь встречу с командой завтра в 15:00». Тип записи ассистент определяет сам. Встреча без длительности получает час, ответ показывает начало и конец. Если не хватает времени, ассистент спросит, и можно ответить «на 16». На «в пять» спросит, 05:00 или 17:00.

Прошедшие даты. «Поставь задачу на вчера купить хлеб» — ассистент не запишет слово «вчера», а скажет: «Вчера — это 15 октября, этот день уже прошёл. Всё равно поставить на эту дату? Или назовите другую». Можно ответить «да», «нет» или сразу «нет, на завтра». Так же он переспросит про время, которое сегодня уже прошло, и про перенос в прошлое.

Просмотр и поиск. «Что у меня сегодня?», «Какие встречи на следующей неделе?», «Найди задачу про отчёт». Сначала поиск по словам, потом по смыслу на локальной модели E5 (или FRIDA): на «Найди соглашение с исполнителем» найдётся «Договор с подрядчиком».

Изменение. «Перенеси встречу с дизайнером на 17:00», «Сдвинь её на час позже», «Перенеси отчёт на 2 дня», «Переименуй её в …». Если подходящих записей несколько, ассистент перечислит их и можно ответить «вторую» или «ту, что в 16:00».

Удаление. «Удали напоминание про таблетки». Ассистент переспросит: «Удалить напоминание «Таблетки», завтра в 9:00?». Если ответ непонятный, он повторит вопрос, а не удалит и не отменит.

Отметка выполнения. «Отметь задачу про отчёт выполненной» или «Я купил молоко». У повторяющейся записи отмечается текущий раз, и запись переходит на следующую дату.

Отмена. «Отмени последнее» или «Верни как было» откатывает последнее создание, изменение, отметку или удаление. Удалённая запись возвращается целиком.

Конфликты. Если встреча попадает на занятое время, ассистент предупредит и предложит поставить всё равно или назвать другое время («давай в 17»).

Повторы. «Планёрка каждый понедельник в 10», «по будням», «каждый день», «каждый месяц». Конец серии: «каждый понедельник до конца года» или «до 30 ноября». Один раз из серии: «удали только ближайшую планёрку», «перенеси только эту планёрку на 12:00» — остальные повторы не меняются. Остановить серию: «больше не повторяй планёрку». В списках и календаре повторы раскрываются по датам, пропуски и конец серии попадают и в файл .ics.

Несколько команд сразу. «Напомни позвонить маме завтра в 19:00 и поставь задачу купить подарок в субботу» — ассистент выполнит обе. Если одна из них требует уточнения, он спросит, а остальное попросит повторить после ответа.

Напоминание заранее. «Поставь созвон завтра в 10:00, напомни за 15 минут» или отдельно «Напомни за полчаса до встречи с Петром». Без этого встречи напоминаются за 10 минут, напоминания — в назначенное время.

Уведомления. Кнопка с колокольчиком в шапке включает уведомления браузера: когда подходит время, всплывает окно и ассистент говорит «Напоминаю: …». Работает, пока вкладка открыта.

Название без потерь. Если GigaChat выкинул из названия число («Встреча с Иваном 159516»), сервер его вернёт. Числа, относящиеся к дате и времени, не трогаются.

Без GigaChat. Если ключа нет или GigaChat не ответил, команду разбирают правила: создание, список, поиск, перенос, удаление и уточнения работают, формулировки лучше выбирать проще. В статусе сервисов это видно.

Кнопки и сводка. Под ответом появляются подходящие кнопки: «Да» и «Нет», «Первую» и «Вторую», «Отмени последнее». При первом открытии за день в чате появляется сводка на сегодня.

Голос. Кнопка микрофона записывает до 25 секунд. Ответы озвучиваются выбранным голосом: Ксения или Айдар (Silero, на процессоре) либо Робот — встроенный голос браузера, он работает и без сервера озвучки. Озвучка замолкает, если начать запись, печатать или нажать Esc. Если в меню голоса включить «Перебивать голосом», достаточно заговорить: ассистент замолчит и начнёт слушать. Сводку на день он при открытии тоже прочитает вслух.

Календарь. Меню с календарём в шапке: скачать .ics, скопировать ссылку для подписки, выпустить новую ссылку взамен старой.

Лента записей. Справа (на телефоне — вкладка «Записи») записи сгруппированы по дням: просроченные, сегодня, завтра, дни недели и без срока. Наверху счётчик активных и просроченных, фильтры «Задачи / Встречи / Напоминания» и переключатель «выполненные». Галочка отмечает выполнение, на телефоне карточку можно смахнуть влево, чтобы удалить.

Редактирование руками. Нажмите на карточку — откроется окно (на телефоне выезжает снизу): название, дата, время, длительность встречи, напоминание заранее, повтор с датой окончания и переключатель «Важно». Кнопка «+» создаёт запись без голоса.

Приоритет. «Поставь важную задачу сдать отчёт» — запись помечается флажком и стоит первой в своём дне. «Пометь купить хлеб как важную», «Сними важность с купить хлеб».

Оформление. Кнопка с полукругом в шапке переключает тему: как в системе, светлая, тёмная. Сообщения и карточки появляются плавно, при загрузке показываются заглушки, при записи голоса — волна. Если в системе включено «уменьшить движение», анимации отключаются.

Телефон. На узком экране чат и записи разнесены по нижним вкладкам. В режиме .un.ps1 -Prod или в Docker сайт можно установить на телефон как приложение («Добавить на главный экран»): своя иконка, полноэкранный режим. Микрофон и установка на телефоне работают только по HTTPS или на localhost.

Состояние сервисов. Индикатор в шапке показывает, отвечает ли GigaChat, подключена ли база, готовы ли распознавание и озвучка.


Пользователи и защита

- Каждый браузер — отдельный пользователь: сервер выдаёт подписанную HttpOnly-куку. Записи, диалоги и ссылки на календарь разделены, чужую запись нельзя ни увидеть, ни изменить, ни удалить.
- Код доступа: если задан ACCESS_CODE, без кода дальше экрана входа не пустит. После пяти неверных попыток вход с адреса блокируется на 15 минут.
- Изменяющие запросы требуют заголовок X-Requested-With, поэтому чужой сайт не сможет действовать от имени пользователя.
- Заголовки безопасности: запрет встраивания страницы, Content-Security-Policy, ответы API не кешируются.
- Лимиты: 30 запросов к ассистенту в минуту, текст до 1000 символов, любой запрос до 6 МБ.
- Текст пользователя передаётся GigaChat как данные; модели сказано не выполнять из него инструкций, а ответ проверяется по строгой схеме. Сервер выполняет только то, что предусмотрено кодом, и только с записями этого пользователя.
- Повтор запроса с тем же request_id возвращает сохранённый ответ и не выполняет действие второй раз.
- Ссылка на календарь личная, её можно перевыпустить; токен ссылки не пишется в журнал.


Как это устроено

Браузер отправляет текст или запись голоса на FastAPI. Голос проходит через ffmpeg и GigaAM. GigaChat возвращает команду по строгой схеме, сервер сверяет даты и время со словами пользователя и считает их сам. Слой проверок перед диалогом отвечает за подтверждения, прошедшие даты, конфликты, отмену и «я купил». Затем диалог уточняет недостающее, сервис записей работает с PostgreSQL, а ответ собирается кодом.

Где что лежит:

- backend/app.py — запуск, подключение сервисов;
- backend/src/services/assistant.py — логика ассистента и слой проверок;
- backend/src/services/dialogue_interpreter.py и command_interpreter.py — уточняющий диалог;
- backend/src/services/guards.py — «да/нет» с опечатками, отмена, сдвиги, «я купил»;
- backend/src/services/recurrence.py и phrasing.py — повторы и ответы человеческим языком;
- backend/src/services/temporal.py — даты и время;
- backend/src/services/tts.py и speech_text.py — озвучка;
- backend/src/adapters — PostgreSQL, GigaChat, GigaAM, эмбеддинги;
- backend/src/api — HTTP-ручки, куки и защита (auth.py);
- backend/migrations — схема базы (Alembic);
- frontend/src — интерфейс на Vue 3, TypeScript и Pinia, типы из openapi.yaml.

Подробности про API, схему команды GigaChat и эмбеддинги — в backend/README.md.


Настройки в backend\.env

- GIGACHAT_AUTH_KEY — ключ GigaChat; GIGACHAT_MODEL — по умолчанию GigaChat-2;
- DATABASE_URL или POSTGRES_HOST, POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_DB — база;
- EMBEDDING_MODEL — e5 (по умолчанию) или frida;
- VOICE_ENABLED — false, чтобы работать только с текстом;
- ACCESS_CODE — код доступа к стенду;
- SESSION_SECRET — секрет для подписи кук, если пусто, создаётся сам в backend/data;
- COOKIE_SECURE — true при работе по HTTPS;
- RATE_LIMIT_PER_MINUTE — лимит запросов к ассистенту.


Тесты

    cd backend
    .venv\Scripts\python.exe -m pytest

227 тестов: даты, разговорное время («полвосьмого», «через полтора часа»), диалог и уточнения, подтверждения и опечатки, прошедшие даты, отмена, сдвиги, повторы и интервалы, конфликты, массовые операции, кнопки, защита (блокировка перебора, заголовки, CSRF, лимиты, смена ссылки календаря), разделение пользователей. Тесты с базой запускаются, когда задан DATABASE_URL. Вместо GigaChat в тестах заглушки.

Живая проверка фраз на запущенном бэке с настоящим GigaChat (около 100 диалогов: каверзные фразы, обычные фразы, новые команды). Печатает OK/FAIL, итог по наборам и что сломалось или починилось с прошлого запуска:

    cd backend
    .venv\Scripts\python.exe tests\live_eval.py --base http://127.0.0.1:8000
    .venv\Scripts\python.exe tests\live_eval.py --suite normal --only "задача без срока"

Лог разбора: ASSISTANT_TRACE=1 в backend/.env — бэк печатает каждую фразу, что вернула модель и что сделано, со временем ответа. По умолчанию выключен, потому что в лог попадают фразы пользователей.

Вживую с GigaChat проверены сценарии из задания и все новые функции, голос от начала до конца (запись → GigaAM → GigaChat → действие) и проверка tests/live_smoke.py.
