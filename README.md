# Голосовой ассистент для задач и встреч

Веб-приложение для создания, поиска и изменения задач, встреч и напоминаний текстом или голосом. Речь распознаёт GigaAM, команды обрабатывает GigaChat, записи хранятся в PostgreSQL.

## Запуск

Скопируйте `backend/.env.example` в `backend/.env` и укажите `GIGACHAT_AUTH_KEY`.

**Docker (голос и текст).** Нужен Docker; для обычного варианта — доступная контейнерам видеокарта NVIDIA.

```powershell
cd backend
docker compose up -d --build
```

Без GPU используйте `docker compose -f docker-compose.cpu.yml up -d --build`. Интерфейс откроется на [localhost:8080](http://localhost:8080). Первый запуск скачивает модели и может занять время.

**Windows, локальный запуск только с текстом.** Нужны Python 3.11+, Node.js и Docker Desktop. Из корня проекта выполните в PowerShell:

```powershell
.\run.ps1 -NoVoice
```

Скрипт запустит базу, бэкенд и фронтенд. Интерфейс будет доступен на [127.0.0.1:5173](http://127.0.0.1:5173). Для сборки фронтенда и запуска на одном адресе добавьте `-Prod`; тогда адрес будет [127.0.0.1:8000](http://127.0.0.1:8000).
